# NoteWize

A personal note taking app.

## Minimal and Disconnected on Purpose

* All notes are markdown files in a folder.
* No databases.
* No search (in the app, OS handles fine)
* Web tech with Electron.
* Only supports linux.
* Only dark theme.

## Fit for me

This is for me personally. If you like it, fork it, or point an agent at it to
create your own.
